**Endpoint 1 — POST /api/subscriptions/create (requireAuth):**
- Reads `{ planType }` from req.body. `planType` must be `"monthly"` or `"annual"`. If neither, return 400 `{ message: "Invalid plan type" }`.
- Resolves the Razorpay plan ID server-side: `const planId = planType === "annual" ? process.env.RAZORPAY_PLAN_ANNUAL_ID! : process.env.RAZORPAY_PLAN_MONTHLY_ID!;`
- Calls `razorpay.subscriptions.create({ plan_id: planId, total_count: 120, quantity: 1, customer_notify: 0 })`.
- Returns 200 `{ subscriptionId: subscription.id }`.
- On error, return 500 `{ message: "Failed to create subscription" }` and log the error.

**Endpoint 2 — POST /api/subscriptions/verify (requireAuth):**
- Reads `{ razorpay_payment_id, razorpay_subscription_id, razorpay_signature }` from req.body.
- Validates signature: the signed string is `razorpay_payment_id + "|" + razorpay_subscription_id`. Compute HMAC-SHA256 with `process.env.RAZORPAY_KEY_SECRET!` as key. Compare hex digest against `razorpay_signature`.
- If invalid signature, return 400 `{ message: "Invalid payment signature" }`.
- If valid:
  - Determine planType by comparing `razorpay_subscription_id` against the Razorpay API — fetch the subscription via `razorpay.subscriptions.fetch(razorpay_subscription_id)` and read `sub.plan_id`. Compare against `RAZORPAY_PLAN_MONTHLY_ID` and `RAZORPAY_PLAN_ANNUAL_ID`. If monthly set `planType = "pro_monthly"`, if annual set `planType = "pro_annual"`, otherwise default to `"pro_monthly"`.
  - Compute `planExpiresAt`: use `sub.current_end` (Unix seconds) — `new Date(sub.current_end * 1000)`. If `sub.current_end` is not available, compute as now + 30 days for monthly, now + 365 days for annual.
  - Call `storage.updateUserPlan(req.session!.userId, planType, planExpiresAt, razorpay_subscription_id)`.
  - Call `refreshSessionUser(req, req.session!.userId)`.
  - Return 200 `{ success: true, planType }`.

**Endpoint 3 — POST /api/subscriptions/cancel (requireAuth):**
- Reads the user from session. Gets `razorpaySubId` from the DB user via `storage.getUserById(req.session!.userId)`.
- If no `razorpaySubId`, return 400 `{ message: "No active subscription found" }`.
- Calls `razorpay.subscriptions.cancel(razorpaySubId, { cancel_at_cycle_end: 1 })` per D-13 (access continues until period end).
- Do NOT update planType or planExpiresAt here — the `subscription.cancelled` webhook handles this, and `planExpiresAt` is already set from the last `subscription.charged`.
- Return 200 `{ success: true, message: "Subscription will be cancelled at end of billing period" }`.
- On error, return 500 `{ message: "Failed to cancel subscription" }`.

**Endpoint 4 — POST /api/webhooks/razorpay (NO requireAuth — webhooks come from Razorpay servers):**
- Verify signature: Read `x-razorpay-signature` header. Use `req.rawBody` (Buffer) for HMAC-SHA256 with `process.env.RAZORPAY_WEBHOOK_SECRET!`. Compare hex digest against the header signature. If mismatch, return 400 `{ message: "Invalid webhook signature" }`.
- Parse event: `const event = req.body; const eventType = event.event as string;`
- Extract event ID from `event.payload?.subscription?.entity?.id + "_" + eventType` or `event.event_id` if available, for idempotency key.
- Idempotency check: call `storage.getWebhookEvent(eventId)`. If exists, return 200 `{ message: "Already processed" }` (per D-16).
- Log event: call `storage.createWebhookEvent({ eventId, eventType, payload: JSON.stringify(event), processed: false })`.
- Handle by eventType:
  - `subscription.charged`: Extract `subEntity = event.payload.subscription.entity`. Determine `planType` from `subEntity.plan_id` (compare against env vars). Compute `planExpiresAt = new Date(subEntity.current_end * 1000)`. Find user by `razorpaySubId = subEntity.id` — query: look up user where `razorpaySubId` equals `subEntity.id`. If not found, find by notes or fall back. Call `storage.updateUserPlan(userId, planType, planExpiresAt, subEntity.id)`.
  - `subscription.cancelled`: No action needed — `planExpiresAt` is already set from last charge. Just log.
  - `subscription.halted`: Find user by `subEntity.id`. Call `storage.updateUserPlan(userId, "free", null, null)` to immediately revoke (payment retries exhausted).
  - Default: Log and ignore.
- Return 200 `{ status: "ok" }`.
